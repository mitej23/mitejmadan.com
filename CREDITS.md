## Not used

`~/Desktop/pok3` is a modular character *generator* (style `pokemon-gen-3`), not a
sprite sheet — its base layers are palette keys with no head, face or clothes, and
composing them needs the desktop tool that produced it. Nothing from it ships, so
its licence has not been reviewed. If a custom character is ever exported from it,
check that licence first.
